#  Data Pengguna Grup

Jika bot ditambahkan ke grup, kami mengumpulkan:

## Informasi Grup

- Group ID dan nama grup
- Jumlah anggota
- Pengaturan dan konfigurasi bot di grup

## Data Berdasarkan Peran

### Owner Grup

- Memiliki kontrol penuh atas pengaturan bot
- Dapat mengaktifkan/menonaktifkan fitur
- Bertanggung jawab atas penggunaan bot di grup

### Admin Grup

- Dapat mengatur fitur bot tertentu
- Membantu moderasi menggunakan bot
- Akses ke laporan dan statistik grup

### Anggota Grup

- Interaksi dengan bot di grup tercatat
- Pesan yang memicu fitur bot disimpan sesuai kebijakan
- Tunduk pada aturan bot yang ditetapkan owner/admin grup

## Catatan Penting

Owner dan admin grup bertanggung jawab atas penggunaan bot. Anggota grup dianggap menyetujui penggunaan bot dengan tetap berada di grup tersebut.
