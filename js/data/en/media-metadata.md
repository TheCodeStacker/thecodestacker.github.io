## Format Penyimpanan

Metadata media disimpan dalam format pickle (Python serialization) untuk efisiensi dan kemudahan reuse.

## Kelebihan

- Proses lebih cepat saat mengakses data
- Struktur data tetap utuh
- Memudahkan integrasi sistem

## Kekurangan

- Format spesifik Python
- Tidak human-readable
- Memerlukan Python untuk membaca

## Alasan

Metode ini memungkinkan kami menyimpan dan memproses data dengan lebih efisien menggunakan resource terbatas.
