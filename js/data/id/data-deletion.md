# Penghapusan Data

---

## Mengapa Harus Melalui Proses Verifikasi?

Untuk keamanan dan mencegah penyalahgunaan (spam, aktivitas ilegal), penghapusan akun harus melalui proses verifikasi dengan tim kami.

---

## Cara Menghapus Data

1. [Hubungi kami](./contact.md)
2. Berikan User ID dan alasan penghapusan
3. Proses akan dilakukan maksimal **7 hari kerja**

---

## Catatan

Data pelanggaran tetap tersimpan meskipun akun dihapus (sesuai ketentuan penyimpanan).
