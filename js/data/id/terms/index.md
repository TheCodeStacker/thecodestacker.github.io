## ⚠️ Peringatan Keamanan Data

**PENTING - MOHON DIBACA:**

Layanan ini saat ini memiliki keterbatasan dalam enkripsi data. **Tidak semua data pengguna dienkripsi**. Sebelum menggunakan layanan, harap pahami risiko berikut:

### Data yang TIDAK Dienkripsi:
- User ID, username, dan nama lengkap
- Usia dan jenis kelamin
- Preferensi bahasa dan pengaturan
- Log koneksi anonymous chat
- Riwayat penggunaan fitur

### Data yang Dienkripsi:
- ✅ Metadata media Telegram

### Risiko yang Perlu Anda Ketahui:
- Data dapat terekspos jika terjadi data breach
- Pihak dengan akses server dapat melihat data Anda
- Data dapat diminta pihak berwenang tanpa dekripsi tambahan
- Log anonymous chat tersimpan tanpa enkripsi

**Dengan melanjutkan menggunakan layanan ini, Anda memahami dan menerima risiko di atas.**

Baca detail lengkap di [Syarat & Ketentuan](#term-and-condition).

## 🛡️ Rekomendasi Keamanan

Untuk melindungi privasi Anda:
- ✅ Gunakan username yang tidak mengidentifikasi Anda
- ✅ Jangan gunakan nama asli jika mengutamakan privasi
- ✅ Aktifkan fitur "Don't track my account" di bot
- ✅ Minimal bagikan informasi pribadi
- ✅ Pertimbangkan risiko sebelum berbagi data sensitif
