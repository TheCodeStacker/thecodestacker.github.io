# Data yang Kami Kumpulkan

---

## Data Wajib

- User ID, username, dan nama lengkap
- Usia dan jenis kelamin
- Preferensi bahasa

---

## Data Opsional

- Informasi grup/channel jika Anda menambahkan bot
- Data pendukung seperti foto (untuk layanan tertentu)

---

## Tracking

- Waktu interaksi terakhir
- Preferensi dan pengaturan pengguna
- Riwayat penggunaan fitur

Semua data terkait User ID disimpan untuk tracking informasi lengkap Anda.

---

## Opsi Privasi

Anda dapat memilih **"Don't track my account"** untuk tidak dimasukkan dalam database tracking publik.
