# Backup dan Recovery

---

## Kebijakan Backup

- Database di-backup secara berkala
- Prioritas pada data kritis pengguna
- History/log audit mungkin tidak dapat dipulihkan karena keterbatasan resource

---

## Downtime

- Estimasi recovery maksimal **7 hari**
- Kami berupaya semaksimal mungkin mempercepat pemulihan
- Tidak ada jaminan 100% karena keterbatasan resource

---

## Catatan

Backup mungkin tidak mencakup semua data dan dapat mengalami error karena keterbatasan teknis.
