## Sebagai Pengguna, Anda Berhak

- Menghentikan penggunaan layanan kapan saja
- Meminta penghapusan data melalui proses verifikasi
- Mendapatkan informasi tentang data yang kami simpan
- Melaporkan pelanggaran atau masalah keamanan
- Mengajukan banding jika merasa salah di-ban
- Mengaktifkan **"Don't track my account"** untuk privasi lebih
