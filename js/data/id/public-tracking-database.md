# Database Tracking Publik

---

## Fitur Tracking Publik

Kami merekam username dan full name semua pengguna yang menggunakan bot kami. Data ini dapat diakses pengguna lain secara gratis (sesuai kuota tersedia) melalui layanan tracking kami untuk:

- User ID
- Username
- Full name (nama lengkap)

---

## Tujuan

- Membantu pengguna menemukan informasi publik
- Tracking perubahan username/nama
- Verifikasi identitas pengguna

---

## Opsi Privasi - "Don't Track My Account"

Anda dapat memilih untuk tidak dimasukkan dalam database tracking publik ini. Dengan mengaktifkan opsi ini:

- Data Anda tidak akan muncul di hasil pencarian layanan tracking kami
- Username dan nama Anda tidak dapat di-tracking oleh pengguna lain
- Data tetap tersimpan di sistem kami untuk operasional bot, tapi tidak dipublikasikan

---

## Cara Mengaktifkan

Gunakan pengaturan privasi di bot atau [hubungi kami](./contact.md) untuk bantuan.

---

## Catatan Penting

- Jika tidak mengaktifkan opsi ini, data Anda dianggap publik dan dapat diakses pengguna lain
- Perubahan pengaturan mungkin memerlukan waktu untuk diterapkan
